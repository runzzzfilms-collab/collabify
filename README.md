# Collabify

Live collaboration for After Effects.

To install, download the latest Collabify ZXP from the Releases page and open it with ZXP Installer. After that, Collabify updates itself from inside After Effects.

This repository hosts the release files. Installed copies read collabify-update.json from the latest release, so every release needs both files: the ZXP and collabify-update.json.
